# Algorithmic Signals and Social Inequality

Course website on social media recommendation systems and fairness impacts.

## Pages

- `index.html` - Home
- `signals.html` - Signals and data concepts
- `bias.html` - Bias and inequality mechanisms
- `case-studies.html` - Four real-world case studies
- `solutions.html` - Solutions and accountability
- `interactive.html` - Interactive ranking demos
- `resources.html` - Readings and check-in material
